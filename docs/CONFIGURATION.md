# 配置与制图约定

配置文件编码为 UTF-8；相对路径以配置文件目录为基准。未知字段会报错，防止拼写错误被忽略。

| 字段 | 类型/默认 | 用途 |
| --- | --- | --- |
| `boundary` | 必填，路径 | 研究区面数据，必须有已知坐标系 |
| `output_dir` | 必填，路径 | 新建或空文件夹；已有文件即拒绝执行 |
| `project` | 路径 | 独立模式必填，已有 APRX；桥接模式可省略 |
| `template` | `study_area` | 另一种为 `watershed` |
| `world` / `country` | 路径 | 全球陆地/国家范围面，构成两级定位；不自动下载 |
| `dem` | 路径 | DEM 栅格；颜色分级为自动 6 级，具体高程范围来自真实数据 |
| `dem_unit` | `m` | DEM 垂直单位；所有高程图只接受米，其他单位须预先转换，即使关闭阴影也一样 |
| `rivers` / `basins` / `admin` / `sites` | 路径 | 河流线、流域面、行政区面、采样点 |
| `river_order_field` | 空字符串 | 配置后以唯一值分级河流线宽与色彩；可读取实际数据字段 |
| `site_label_field` | 空字符串 | 采样点标签字段，字段存在性会检查 |
| `detail_crs` | `3857` | 主图投影 WKID，必须是投影坐标系。默认 Web Mercator 会警告，论文应显式选择适宜投影 |
| `national_crs` | `3857` | 全国定位图 WKID；示例 `102012` 为亚洲投影，非全球通用选择 |
| `globe_center` | 研究区中心 | `[经度,纬度]`，全球定位图使用该中心的正射投影 |
| `national_extent` | 国家图层范围或研究区 | `[西,南,东,北]`，单位为 WGS84 经纬度 |
| `padding` | `1.12` | 图框范围扩展倍数，允许 1–3 |
| `graticule` | `true` | 自动添加 Esri 样式库中的经纬网，缺失时记录警告 |
| `hillshade` | `true` | 降采样到最长边不超过约 1800 像元，生成显示用 NumPy 阴影，不改变科学数据 |
| `title` / `subtitle` / `source_notes` | 文本 | 标题、副标题和实际来源说明；注意避免过长文本溢出 |
| `language` | `en` | `zh` 切换模板内置标签；用户提供文本原样保留 |
| `font` | `Arial` | 中文推荐 `Microsoft YaHei`，需本机已安装 |
| `dpi` | `300` | 整数，72–1200 |
| `formats` | `["PNG","PDF"]` | 允许 PNG、PDF、SVG |
| `demo` | `false` | 合成示例必须设为 true，添加显著的非科研数据说明 |

地图中每个图框是独立原生 ArcGIS MapFrame，图层仍可编辑。矢量输入保留原始路径引用；派生 DEM 和阴影存入输出目录。边界数据是否为权威、完整版本，需要使用者按自己的研究与投稿要求确认。

三级定位和流域模板都使用横向 A4 布局，图例独立置于右侧，减少遮挡主图。v0.1 不保证任意数量的类别和长标题自动无溢出；导出后检查并在 APRX 中调整。SVG/PDF 中栅格地形仍然是栅格，不能变成可编辑等高线。

水文分析采用 D8，`threshold_km2 × 1,000,000 / 像元面积` 向上取整得到汇流累积像元阈值；ArcGIS FlowAccumulation 表示流入该像元的上游像元数，不包含当前像元。`Basin` 不使用用户指定出口点，没有最小流域面积自动筛选。面积分区采用 DEM 的有效范围边缘出口，请勿解读为任意研究区的标准子流域体系。
