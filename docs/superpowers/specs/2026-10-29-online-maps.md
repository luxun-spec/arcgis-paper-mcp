# v0.2 在线制图需求与验收

用户授权：根据地数空间公开视频改进科研制图，并新增从用户自然语言需求查找互联网栅格/矢量数据、在 ArcGIS Pro 自动制图的能力。本需求取代 v0.1 设计中“不自动下载数据”的限制。

实现范围：客户端 AI 解析需求；MCP 提供有来源目录的区域搜索、面边界下载、真实地形瓦片下载与解码、矢量定位和 journal 模板渲染。多候选需选择；下载预算有上限；不支持的专题、年份须返回缺项。Nominatim 失败时只能精确匹配国家级 Natural Earth 备选，不能擅自替换行政等级。

观察依据：已通过公开网页播放器查看第2、4、5集画面与相关页面；第2集使用小位置图、大专题图与紧凑图例；第5集评论说明内置模板。内部源码和预训练方式未知，不作复制或复现声明。

验收：真实网络查询、下载、GeoJSON 转换、DEM 解码、ArcGIS 原生布局与导出；读取数据来源记录；检查 PNG 与 APRX 重开。纯 Python 和 MCP 协议测试必须通过。GUI 直接打开工程、任意地名和其他数据源不在一次示例测试中自动视为通过。
