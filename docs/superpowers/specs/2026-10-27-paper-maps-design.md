# ArcGIS Paper MCP design

User-approved scope: build an MCP project for editable scientific study-area maps inspired by two supplied reference images; publish source to the user's GitHub. Prioritize a globe locator, national locator and detailed terrain map; also provide a watershed overview template.

Implementation decisions: Python 3.11+, official MCP Python SDK v1 (pinned below v2 for compatibility), ArcGIS Pro 3.4+ / ArcPy. A separate stdio server communicates with a local file-queue bridge, or launches ArcGIS Python against a supplied APRX for headless jobs. The Pro bridge snapshots CURRENT on the Pro Python thread, then a single worker opens that explicit file path; it never passes CURRENT COM references across threads. No Qt dependency or network/executable-code endpoint. Typed operations only; atomic request/response files, request expiry and serialized execution. Server uses a private configurable queue, no network listener or API key.

Deliverables: package, CLI, MCP tools, Pro bridge launcher, JSON configurations, offline synthetic demonstration data generator, two templates, editable APRX and PNG/PDF/SVG exports, Chinese guide, meaningful validation and protocol tests, GitHub CI. All data source paths and CRS must be checked. Unknown CRS is rejected. No automatic data downloads or invented real-world boundaries. Synthetic demo clearly marked. Input APRX never overwritten; output must be a new directory. Export manifest records sources, projection, parameters and warnings. Watershed derivation requires Spatial Analyst, projected metre DEM, explicit accumulation threshold and optional basin inputs. Area parameters must use cell area, not fixed cell counts.

Cartography: terrain colors and relief, rivers, administrative boundaries, sites; configurable English/Chinese labels, fonts, north arrows, dynamic scale bars, graticules, legends. Use native ArcPy map surrounds and grids where available; report warnings rather than silently claiming missing elements. Globe locator uses orthographic projection; national and detail maps use separately configurable projections. Users supply authoritative boundaries and data. Do not redistribute reference images or local research datasets.

Validation: unit tests independent of ArcPy for configuration, layout geometry, queue expiry/path safety and operation dispatch; actual ArcPy run against synthetic data when the installed license permits; MCP stdio tools/list + tools/call smoke test; inspect rendered map output before claiming visual success. Publish only repository source, synthetic preview and portable examples; omit user paths, credentials and generated GIS data.
