# Pro 原生中文需求窗口

用户最终选择 ArcGIS Pro 内的窗口，并要求参考地数空间视频的需求输入、对话记录、执行进度和地图展示。此前独立窗口原型已撤出最终产品。

采用 Pro 3.6 SDK / .NET 8 WPF DockPane，按钮位于“论文制图 → 需求输入”。侧栏提供多行需求、对话、运行日志、进度、制图参数、模型设置、边界候选和成果操作。可停靠或浮动。完成后通过 PAGX 向当前工程添加新布局并打开视图，原始工程不自动保存。

保留第三版制图内核和 MCP 接口。插件包内嵌 Python 源文件，由当前 Pro Python 启动受限工作进程。允许 plan/search/ping/render，不接受任意 Python 或命令。请求经 stdin 传递；模型 Key 不落盘。子进程退出后才读取单个响应文件；避免本机加密 AppData 的临时文件 rename/replace WinError17。下载缓存位于用户目录 .arcgis-paper-mcp/pro-search。

有模型时调用用户配置的 HTTPS/localhost Chat Completions JSON 接口，严格校验解析结果。无模型时用有限地名规则和明确地区字段，不能宣称完整自然语言理解。界面明确参数优先。对于土地利用、影像、气象、河流、采样点和指定年份/分辨率需求提示停止。多候选暂停选择；停止按钮只停止后续步骤，不杀死写文件的进程。

新增真实测试案例：青藏高原只用 DEM。公开地名检索只有位置点，不能冒充面边界。接入全球变化数据仓储张镱锂等2021年完整自然地理边界（DOI 10.3974/geodb.2021.07.10.V1），跨九国，并非仅中国境内。运行时下载，不把受再分发限制的数据打包到 GitHub。使用 Albers 等积投影（Esri 102025）覆盖广域，级别6用于64瓦片预算内的整区布局测试。级别7需98瓦片，明确调整参数，不暗中降采样。

验收：真实 Pro 加载插件、在侧栏输入青藏高原需求、真实下载和导出、自动导入原生布局；检查最终 APRX 引用和 PNG/PDF/SVG/PAGX。没有用户模型凭据，真实远程模型调用标为未测，用本地模拟服务检查协议和凭据保护。
